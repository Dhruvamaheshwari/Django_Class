# Django Project

A simple Django project for learning and practicing Django views, URL routing, and basic HTTP responses.

## Features

- Django project setup
- Simple views using `HttpResponse`
- Dynamic URL parameters
- Menu item lookup
- Movie ticket lookup
- Basic inline CSS styling

## Technologies Used

- Python
- Django
- HTML
- CSS
